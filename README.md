# deivid-v-space
True 3D third person shooter game in Godot

## overview
**dvs** is a team-based multiplayer 3d space combat game. Players take control of individual spaceships and work together to achieve a single objective: destroy the opposing team’s space station while defending their own.

### core gameplay
- players are divided into two teams.
- each team has a space station that serves as their main base.
- the primary objective is to destroy the enemy team's space station.
- players control spaceships, engaging in combat, defense, and tactical maneuvers.
- matches end when one team’s station is destroyed.
